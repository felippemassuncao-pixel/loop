📂Por que fiz o código desta maneira?📂

No código eu utilizei um pasta para guardar os resultados de quantas respostas foram dadas, fazendo com que eu conseguisse usar o for para a repetição e facilitando a contagem final utilizando o Q1, Q2 e Q3 para armazenar os 3 possíveis tipos de resposta.

Desta forma, o código fica mais bonito e fácil de ler facilitando a interpretação caso outro programador se depare com o código em algum lugar.
